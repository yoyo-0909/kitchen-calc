# Contributing to Kitchen Calc

Thank you for helping improve Kitchen Calc.

## The UI is locked

The current application interface must remain visually unchanged unless the project owner explicitly updates this requirement.

Do not redesign or modify:
- Colors, gradients, typography, or visual effects
- Layout, spacing, sizing, or component arrangement
- Navigation structure or labels
- Responsive presentation or existing interaction styling

You may improve functionality, fix bugs, improve accessibility behavior, and update maintainability or documentation, provided those changes do not alter the existing visual design.

## Development guidelines

1. Keep the app runnable as a standalone HTML file unless the project direction changes.
2. Avoid unrelated refactors and unnecessary dependencies.
3. Keep changes focused and explain why they are needed.
4. Test the affected workflow in a modern browser.
5. Check light and dark appearance where relevant.
6. Verify that navigation and unrelated workflows still work.
7. Update documentation when setup or behavior changes.

## Pull request checklist

- [ ] The change solves a clearly described problem.
- [ ] The original UI has not been redesigned or visually changed.
- [ ] The affected workflow has been tested.
- [ ] Existing unrelated workflows remain functional.
- [ ] Documentation has been updated where necessary.
- [ ] No secrets, credentials, or personal data were committed.

## Reporting issues

Include clear reproduction steps, expected behavior, actual behavior, and browser/device details when relevant. Screenshots are welcome for explaining a bug, but are not permission to redesign the interface.
